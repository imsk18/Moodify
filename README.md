# 🎵 Moodify

## 📌 About Project

**Moodify** is a MERN-stack music recommendation web app that detects the user's mood and suggests songs based on their current mood. Users can also play recommended songs and enjoy a personalized music experience.

## ✨ Features

* 🎭 Mood Detection
* 🎵 Mood-Based Song Recommendations
* ▶️ Play Songs
* 🔐 User Authentication
* 👤 Personalized User Experience

## 🛠️ Technologies Used

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Authentication:** JWT
* **Languages:** JavaScript
